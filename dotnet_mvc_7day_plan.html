Learning Science
Why this plan works
🧠 Spaced Repetition
Review at increasing intervals. Each day ends with a recall prompt before sleep for maximum consolidation.
💡 Sleep consolidates new neural pathways. The recall prompt before bed is the most important 2 minutes of each day.
⚡ Retrieval Practice
Trying to recall — even struggling — strengthens memory far more than re-reading.
💡 Sit with the struggle for 60 seconds before looking up an answer. The struggle IS the learning.
🔀 Interleaving
Mixing topics feels harder but produces much stronger long-term retention than mastering one topic before moving on.
💡 Days 3–4 mix EF Core and UI concepts on purpose. Discomfort = signal it's working.
🏗️ Elaborative Interrogation
"Why does X work this way?" connects new knowledge to existing knowledge, building richer mental models.
💡 Ask: how does this connect to something I already know? That connection becomes the memory hook.
🔨 Deliberate Practice
Each day has a build session that forces production output — including intentionally making and fixing errors.
💡 You learn faster from fixing a bug than from following a tutorial.
🧩 Chunking
Day 1 builds the master chunk — the request lifecycle — that every future concept hangs off.
💡 Trace one HTTP request in the debugger on Day 1. That chunk is the backbone of everything.
